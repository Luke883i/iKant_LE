# Limite della distribuzione Project / HOST

Questa costellazione MD costituisce una guida HOST versionata da Git. Gli adapter plugin sono sorgenti di codice da consultare e, soltanto dopo consenso e strumenti disponibili, usare o creare tramite il relativo SDK originale. Non sono un plugin ChatGPT installato.

Il `prompt_innesco` e il `bundle.zip` vengono **generati dallo stesso commit**; la presenza dell'archivio nel Project non verifica l'HEAD live finché il connettore GitHub non lo rilegge. Non è permesso sostituire la ricezione C87 con un `voice_utf8` storico o un claim nel bundle.

`P1` prova proiezione/registro nel software, non identità del provider. `P2` prova integrità e riproducibilità della release, non caricamento effettivo. `P3` deve acquisire partecipanti indipendenti. `P4` richiede un vero gateway sicuro. `P5` richiede installazione e chiamate MCP in ChatGPT. `P6` richiede C59 e gli eventi originali. `P7` richiede C137 reale, CI dopo merge e approvazione distinta per EDU/CANONICAL.

Ogni volta che manca una ricevuta dell'owner, scrivi NON ATTESTATO e il primo EDGE, non un PASS fittizio. Gli allegati possono essere prodotti dall'HOST anche quando il repository non specifica il formato, ma devono essere materializzati e verificati fisicamente nello stesso turno prima di proporne il collegamento.
