# Ricette operative HOST per adapter iKant — nessuna installazione implicita

* Capacità native: individua in elenco tool soltanto iKant MCP realmente callable. La sorgente del plugin nello ZIP non crea una connessione. Se non esiste, segnala `MCP_NOT_CONNECTED`.
* **Discover first:** after selection inventory bundled adapters, available MCP tools, Node and source-verified checkout. Try the existing C135 EDU owner rather than inventing a second owner. Report any missing capability only after searching existing adapters and original repo routes.
* **First source blocker after mode:** offer the direct GitHub ZIP for the exact frozen SHA, `https://github.com/Luke883i/iKant_LE/archive/<PINNED_HEAD>.zip`; never ask for a nonexistent downloadable `.bundle` or a terminal step when this ZIP exists. An offline source rehydrator must independently verify original commit bytes, Git tree and clean shallow checkout before C135.
* Capacità EDU locale: verifica se Node è effettivamente disponibile, codice e dependencies originali sono fisicamente presenti, blob C70/C107/C135/C87/C125 e HEAD sono confrontati con `main` live. Senza consenso umano del turno e ricevuta originale **non** eseguire il runtime; rispondi HOST con A=NO_VOICE.
* Creazione adapter: usa solo contratto/repository originali e tool di sviluppo realmente disponibili; un adapter HOST non può conferire native identity o consenso. Quando servono servizi esterni, distingui sorgente, deployment e registrazione ChatGPT.
* Invio incerto: STOP, rilegge il ledger originale e la ricevuta gateway, non ripetere la chiamata finché la riconciliazione indipendente non è disponibile.
* Allegati: se la compressione perderebbe atomi, compila un registro HOST con testo integrale, fonte, digest e atom ID, materializza il documento, rileggilo. Chiama i file `HOST`, non `ikant_voice` e non C59 DOCX.
* Impossibilità: in assenza di tool, mostra comunque sei slot e una risposta HOST utile, marcando limitazioni e un solo NEXT, senza chiedere segreti in chat.

I mini-prompt per i singoli slot sono `04_FILLER.md`. Il rendering in linea è una richiesta di formato, non un widget o un ledger duraturo. I soli eventi provider originali attestano CANONICAL, mai i documenti Project.

* **Pacchetto candidato:** `adapter_source/scripts/host-rehydrate-source-zip.py` viene distribuito nel Project ZIP insieme a `PINNED_COMMIT_OBJECT.raw`. Il Project non esegue automaticamente lo script: occorre un ambiente Node/Python realmente callable e il file ZIP umano caricato, sempre dopo i gate.
