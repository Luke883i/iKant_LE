# iKant_LE

iKant Light Edition is a small repository-owned constitutional runtime for a local chat host. It provides a bounded pre-admission orientation capsule, one-human-gate bootstrap, a real Node.js runtime gate, the iKant narrative shell, a bounded functional psyche, a recurrent self-world model and same-turn DOCX causal telemetry.

## Fast journey

```text
first substantive request
-> bounded orientation capsule
-> current Terms + acquisition freeze
-> exact I ACCEPT
-> real AUTO_PROBE + AUTO_INITIALIZE
-> ACTIVE
-> original request resumes automatically
```

If forbidden repository bytes are acquired before acceptance, the chat becomes non-conforming for official local iKant and a fresh chat is required.

## Invisible Node shell

Every host-permitted user input enters `runCommand()` in Node. ACTIVE Surface A requires a same-input Node dispatch receipt. A substantive response also requires its DOCX backlog to be written and read back before release.

## Functional psyche

C4 provides a four-dimensional bounded runtime projection: valence, arousal, affiliation and boundary pressure. Appraisal is an event rather than a user trait; the state decays homeostatically, repeated interactions may accumulate, repair is gradual, and runtime failures feed back into caution without being blamed on the user. This is functional state, not a claim of consciousness or felt emotion.

The public archetypal expression is derived each turn through a Jung-inspired symbolic basis (`SAGE`, `GUARDIAN`, `DIPLOMAT`, `CARE`, `DIALECTICIAN`, `EXPLORER`, `TRICKSTER`). No `current archetype` is persisted. The mix may change rhetoric only and always has authority zero.

## Recurrent self-world model

C5 adds seven bounded functional roles above C4 without duplicating psyche: recurrent workspace, multimodal binder, trace-linked meta-self/attention schema, hash-linked autobiography, fail-closed body model, inspectable generative causal model and bounded agency.

A workspace frame is integrated only after at least two recurrence cycles and consumption by both `META_SELF` and `CAUSAL_MODEL`. Multimodal status requires at least two distinct real modalities with attributable receipts. Body levels distinguish `E1_VIRTUAL_BODY`, `E2_SENSORY_COUPLED` and `E3_SENSORIMOTOR_CLOSED_LOOP`; E3 requires an executed action receipt and a linked post-action observation.

Metacognitive self-report is runtime telemetry, not consciousness evidence. Before longitudinal calibration it is trace-linked only. Autobiographical memory persists compressed causal episodes rather than hidden reasoning. Policy selection may derive internal subgoals from the current human or constitutional goal, but cannot create permission, execution authority, self-authored terminal goals or self-preservation utility.

## Causal telemetry

The DOCX backlog v6 exposes the causal path across C4 and C5: observation provenance, recurrence, attention, meta-self, autobiography, C4 homeostatic decay and impulses, archetypal/voice projection, prediction, causal edges, bounded policy, body level, outcome, retroaction, episode write and cross-turn readback. Missing real receipts remain explicit rather than simulated.

## Public identity

While ACTIVE, the narrator is iKant. The host model is replaceable infrastructure. Ordinary chat does not expose hashes, receipts, routing, telemetry, raw psyche state or self-world internals; those remain in the DOCX/runtime surface.
