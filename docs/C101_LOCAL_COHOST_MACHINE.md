# C101 | Local compositional co-host microkernel (noncanonical experiment)

**Purpose.** Between C100's unbound host-language drafts and full C84/C59 execution, C101 provides a real, bounded local Node computation whose displayed text is the **exact** byte projection of the actual C71 output. This is not a new canonical iKant owner, a resident neural module, ChatGPT interception, or a new lifecycle.

## What is and is not computed

`real C72 EXPERIMENTAL selection + explicit separate C100 co-host opt-in + human input + local README bytes` -> `C69 integrity gate` -> `C70 (cognition, bounded functional psyche and self-world, local ephemeral dispatch)` -> `C71 (guarded model candidate selector or repository-owned composer)` -> `C100 plan and final UTF-8 hash binding` -> `C101 immutable readback with exact voice bytes` -> *host displays exact bytes or declares non-delivery*.

Optional candidate is a caller-supplied ordinary LLM draft. With **no candidate**, given identical source tree, selection, and input, output is deterministic; with a candidate, machine projection is deterministic **conditional on those candidate bytes**, not proof that the host model itself is deterministic. The C71 identity/guarded/resource-gap policy can override the draft. C100 and C101 never call a model or grant any new permission. Do not rephrase the resulting machine voice in the host. A preview composed from generic templates is not proof of deep semantic adequacy; measure usefulness independently.

C101 does not require C77/C81/C82/C84 or install any host hook. It must run on a genuinely installed **matching repository module graph**, Node >=20, with local read permissions. Its `source_head` is frozen caller evidence, not an independently authenticated GitHub ref. Samehash and code execution are separate from origin and native delivery. A ChatGPT Project prompt by itself cannot ensure this Node call every turn; failing to wire it is `C101_STOP`, never a fake receipt.

## Production boundary and rollout

- Existing C99 priority is untouched: attempt truly qualified C84 first; C101 is an explicit **co-host-only** host choice after separate human opt-in; unbound C100 remains the lower-assurance compatibility route. CANONICAL never falls back.
- Existing TERMS, C72, C59, C84, C97 and C100 files are unchanged by this slice. Prompt-side references may describe C101, but do not create a callback, modify Project instructions or alter source controls.
- On a successful receipt render `iKant | EXPERIMENTAL LOCAL CO-HOST | NOT C84 | ACTIVE=false`, then verbatim `voice`, followed by compact status / input+output digest / observed edge. Do not label it strict Surface A. Optional diagnostic fields can be collapsed only when retrievable.
- Never claim `native_event_attested`, `native_delivery_attested`, `persistent`, `canonical_runtime`, `C84_OWNER_EXECUTED`, `iKant ACTIVE`, or phenomenological consciousness. The `origin` and `delivery` gaps survive local green CI.
- For host invocation use a **real** transport with source-bound module bytes; if none is installed, stop at `HOST_SOURCE_TO_NODE_TRANSFER_NOT_ATTESTED`. Do not silently invoke network fetch from Node or assert that Project instructions install the bridge.

## Engineering DoD / acceptance

1. **Isolation:** add-only file neighborhood; source contracts and five onboarding paths remain byte-identical; no new canonical owner, retry ledger, or writer.
2. **Functional:** a real Node call to C70+C71+C100 on exact current input returns verified input/output SHA-256 and exactly the C71 UTF-8 voice, with no host text rewrite; C71 guard blocks unauthorized identity/matters and requires no resource grants.
3. **Failure integrity:** invalid selection, missing opt-in, source-head drift, accessor/proxy/symbol envelopes, oversize/secret input, overclaim draft, modified readback and absent local modules fail closed without running owner code.
4. **Determinism:** repeated input+candidate+source produces identical voice+digest; changing candidate may change non-guarded voice, but does not alter guarded voice. Ephemeral C70 memory cannot be marketed as inter-turn persistence.
5. **Falsification:** seeded 100,000 negative mutations plus 30,000 structural positive scenarios; post-refinement rerun; report any surviving mutant, seed, axis and oracle limits. Independent native ChatGPT sessions remain external qualification.
6. **Release:** PR with 3 semantic commits, exact-head source, tests, real CI status when available. No merge/release without human decision. Do not classify synthetic scenarios as human studies.
