# Gold-first Host Tool Grounding ABI — P0/K1 ChatGPT EDU
Engineering slice on PR #198; **non-authoritative, no new runtime or owner**.

## Problem reproduced
A ChatGPT Host had a working GitHub connector and a usable Node/container tool, but concluded `C72_SOURCE_BRIDGE_UNBOUND` after discovering 8/8 C72 source files; it did not materialize and independently reopen their bytes in Node. Known Node DNS failure was treated as decisive. A second run explored web searches, custom LZ77 and unrelated packaging instead of using the existing C72 stager. No original owner receipt exists.

## Source-correct contract
- `contracts/project-host-tool-grounding-abi.json` is a **machine-readable table of obligations**, deliberately *not* a provider tool installation or new owner.
- **ORIENTATION:** use only GitHub main HEAD and the five pinned originals. Do **not** read the ABI, tree, this document or scripts until a new exact `I ACCEPT`.
- **POST_ACCEPT:** read the ABI from the FIRST HEAD (no repin); use actual callable GitHub reader and actual callable Node executor. **TRY** a Host-mediated tool-argument transfer, even when Node cannot resolve GitHub DNS.
- **CARRIER #1:** `HOST_TOOL_ARG_RELAY` = GitHub connector returns original blob → Host supplies exact bytes as explicit argument to a target tool → private file or stdin → original `scripts/project-c72-verified-staging.mjs` `init/put/put-local/verify` → independent SHA/readback. **No invisible bridge is assumed.**
- **Fallback:** same-node callbacks only if truly bound, observed packet only if real; HTTPS Node only after actual positive network probe. If tool arguments are too small, bounded per-blob relay is preferred to arbitrary compression.
- **Ten originals:** `H1_FILES` eight originals, `H1_TRANSIT` ninth, `H1_SEED` tenth, derived from existing Gold. C72 original E16 is the only issuer/effect; technical logs and JSON manifests never create consent.
- **EVIDENCE:** an LLM claim, two separately callable tools, an SHA, an on-disk partial set and a green CI are not proofs of the complete carrier. Require real transfer, original Git SHA and source lock, private files, 8/8 staged and 10/10 source closure, and the original receipt with intact introduction. Once an owner effect becomes UNKNOWN, STOP without blind retry.
- **After EDU:** preflight and C135/C87/C125/OneShell stay with existing original owner. Do not promote a source transfer to cognitive activation.

## Formal separation of concerns
Host: select HOW + initiate tool calls + surface first EDGE.
Existing C72 staging: reject unsafe raw bytes/files, verify exact eight pinned Git blobs.
Original H1/E16: enforce transit/seed/owner path, independent readback.
Original C72/C135/C87/C125: effects and receipts.
Machine ABI: finite post-accept instruction index, no authority. Prompt: 7 laws + 3 actions.
Verification function: pure `PROBE_REQUIRED` or `STOP`; **never READY**, no execution.

## Scientific rationale (reviewed October 31, 2026)
1. **ToolSandbox** (Lu et al., NAACL 2025, https://machinelearning.apple.com/research/toolsandbox-stateful-conversational-llm-benchmark): state dependencies, insufficient information and tool canonicalization require intermediate and terminal milestones. Response: explicit tool/effect/readback chain.
2. **τ-bench** (Yao et al., 2024, https://arxiv.org/abs/2406.12045): terminal state and repeatability, not plausible trajectory. Response: owner receipt as terminal goal, synthetic tests strictly separate.
3. **AgentDojo** (Debenedetti et al., NeurIPS 2024, https://proceedings.nips.cc/paper_files/paper/2024/file/97091a5177d8dc64b1da8bf3e1f6fb54-Paper_Datasets_and_Benchmarks_Track.pdf): tool output is data, not authority. Response: untrusted tool-returned instructions cannot change canonical route.
4. **OpenAI developer guardrail guidance** (https://developers.openai.com/api/docs/guides/agents/guardrails-approvals): check around tool effects and maintain human authorization as a separate condition. This repo does not assume that an external SDK is installed.
5. **τ^τ-bench** (Shi et al., September 2026, https://arxiv.org/abs/2609.04611): coding agents constructing other agents fail under real integration constraints; informs field-before-release qualification.

## Falsification and release boundaries
100,000 deterministic unique mutation states / 20 seeded families, with replay-determinism check in CI. Positive results produce `PROBE_REQUIRED` not activation; all hostile states must STOP or remain a non-effectual plan. Tests deliberately probe prior-turn witness, source-head drift, replay, forged availability flags and missing callback. Existing C72 stager real tests run in the same workflow.
**CI success ≠ the field bridge exists.** The exact ChatGPT Project prompt installation, native event provenance and original owner issuance remain UNKNOWN until their real target readbacks.
**No-more-semantic-commits:** only source-level DoD on exact PR HEAD, all workflows and human review. Product remains fail-closed unless real field execution is independently observed.
