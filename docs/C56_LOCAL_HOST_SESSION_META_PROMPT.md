# C56 — Local-host session meta-prompt

C56 is a zero-authority natural-language projection over the merged C46–C55 trajectory. It guides a host language model through admission, bootstrap and later session use without adding a runtime owner, lifecycle, planner, state writer, retry memory, host-frame owner or native-host capability.

## Trajectory compressed

- C46–C49 separated co-host relation, runtime capability and canonical-product status.
- C50 separated native transcript identity from co-host/full-runtime state.
- C51–C53 made bootstrap, execution, route and same-session/native evidence fail-closed; C52/C53 additionally made the per-turn scheduler grant an independent native proof obligation.
- C54 introduced the first honest host-consumption boundary: one validated authority-zero host frame carrying exact shell/artifact/promise projections in baseline, limited and ACTIVE states.
- C55 removed caller-side shadow planning, retry memory, evidence fabrication and NEXT-owner laundering.

## Draft challenged

The supplied long-form draft is retained only as a negative semantic control. It reintroduced several risks already removed by C55: calling the caller-facing entrypoint the NEXT owner, maintaining caller-side semantic memory, treating UNKNOWN as an automatic PROBE, and generically minting receipts from observations. It also left the C54 all-phase host frame, later-turn route and independent native per-turn grant underspecified.

C56 preserves the useful fail-closed intent while removing those regressions.

## Selected normal form

`entrypoint -> one owner directive -> one physical action -> schema-admitted evidence when re-entry requires it -> handoff -> runtime route -> validated all-phase host frame -> required verified artifacts -> exact ASCII shell`

A consumed directive is not future authority. Later iKant turns and `EXIT IKANT` use the validated runtime/host route. The model does not resume bootstrap planning after handoff and does not answer as iKant when the frame/route is unavailable.

Terms remain an owner-presented gate: only a later message exactly equal to `I ACCEPT` is acceptance; the caller neither infers it nor introduces another gate.

Native identity remains external. Labels, prefixes, app/widget presentation, co-host relation, full runtime, control ownership or product status are not native transcript proof. The prompt requires same-session host evidence for a persistent participant lease, an independent per-turn scheduler grant/standing, and native exact-byte delivery/readback.

## Qualification

C56 uses 10,000 seeded semantic worlds across 80 fault families and nine abstraction levels: lexical, directive/authority, evidence/provenance, retry/temporal, admission, handoff/runtime-route, host-frame/UX, native-identity and composite cross-phase. It enumerates the complete `2^20 = 1,048,576` architecture lattice; the selected contract must be the unique minimum and all 20 deletion mutants must be killed.

The selector measures both merged C55 and the supplied long-form draft as explicit negative controls. A separate 100,000-case prompt/machine falsifier mutates the actual rendered natural-language prompt and machine invariants with an oracle implementation distinct from the candidate validator.

Mutation/falsification is engineering evidence only, never physical-host proof.
