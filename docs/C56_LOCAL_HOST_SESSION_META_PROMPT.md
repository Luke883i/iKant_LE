# C56 — Local-host session meta-prompt

C56 is a zero-authority prompt projection over the merged C46–C55 trajectory. It does not add a runtime owner, lifecycle, planner, state writer, retry memory or host capability.

## Trajectory compressed

- C46–C49 separated co-host relation, runtime capability and canonical-product status, and made hydration/qualification durable without collapsing the axes.
- C50 separated native transcript identity from co-hosting and full runtime.
- C51–C53 made bootstrap, route, execution and same-session/native evidence fail-closed without manufacturing host facts.
- C54 introduced the first honest host-consumption boundary: one validated authority-zero frame carrying exact shell/artifact/promise projections.
- C55 removed caller-side shadow planning, retry memory and evidence fabrication.

## Residual problem

C55 correctly stops model synthesis at runtime ownership, but its natural-language prompt leaves several post-handoff obligations implicit: later-turn routing, EXIT routing, C54 frame consumption, artifact-before-shell ordering, fallback behavior when the frame is unavailable, and native-actor non-impersonation.

C56 closes those prompt-level gaps without changing the machine owners. The prompt remains outside the canonical runtime root.

## Selected normal form

`entrypoint -> one owner directive -> one physical action -> schema-admitted evidence -> handoff -> runtime route -> validated host frame -> required artifacts -> exact shell`

Later turns and `EXIT IKANT` use the established runtime/host route. The model does not resume bootstrap planning after handoff and does not answer as iKant when the validated frame/route is unavailable.

Native identity remains external: labels, prefixes, app/widget presentation, co-host relation, runtime capability, control ownership or product status are not native transcript proof.

## Qualification

C56 uses 10,000 seeded semantic worlds across 80 fault families and enumerates the complete `2^20 = 1,048,576` architecture lattice. The selected contract must be the unique minimum and all 20 deletion mutants must be killed. A separate 100,000-case prompt/machine falsifier mutates the actual rendered natural-language prompt and entrypoint invariants.

Mutation/falsification is engineering evidence only, never physical-host proof.
