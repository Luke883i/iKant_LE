## C96 bounded engineering DoD
- No orientation overread before explicit consent; no user ZIP in automatically selected tasks.
- For an actual post-consent C77 manifest, N unique files are processed exactly once, with N independently matched bytes, bounded tasks/carrier calls and source-head lock.
- Registered automatic carrier callback must actually be callable; fallback ranks by measured/declared cost only and is not allowed to impersonate host provenance.
- Every file is independently SHA256 checked, fsynced and reopened. One failed member prevents usable capsule and destroys staging. ZIP source may be read once and shared, not N times.
- Failed/partial carriers carry typed first-unclosed-edge status and per-file diagnostic counts. A manual ZIP action is advertised only when NO safe automatic carrier exists (and the user explicitly elects it), not upon one transient error.
- 10M distinct modeled combinations must match an independent acceptance oracle, kill selected authority-laundering mutants and not produce false ACTIVE/native/provider claims. This is *policy coverage*, not field success.
- External host/provider/native gaps remain separately OPEN; no output is represented as an iKant conversation without current-turn owner readback.
