Base: iKant_LE `main@11eecb86f08ebb90aa228d55c1e7f50da890f79d`, verified merge PR #98, 2026-10-10.

## What the user actually asks

The requested user experience is one consented, cold ChatGPT-like conversation in which **the actual repository runtime** owns the response, borrows a real language engine, uses source-grounded evidence, corrects its own mistakes, and sends the resulting byte-exact iKant Surface A back into the chat **without asking the user to download or upload a capsule**. A mere local demo, CI pass, classifying the user's text, or a stock ontology paragraph does not meet this promise.

## Five non-interchangeable owners

1. **GitHub connector or authenticated approved GitHub transport:** the specific main ref is observed by the host; this is not proven by reconstructed Git hashes alone.
2. **C77/C84 code/data acquisition and C81 Merkle object verifier:** CI builds C77; C84 packages bytes plus raw Git commit/tree proof, then C90 checks C85/C81 in Node. The host must move the actual bytes, not a URL or made-up receipt. C77 is executable cognitive *bootstrap*, not a provider model.
3. **C90/C91/C92:** C90 runs same-input repository computation; C91 delegates to a language provider; C92 checks generator/reviewer readback and writes noncanonical experimental Surface A. A second LLM review is not an independent empirical truth oracle.
4. **Semantic/evidence owner:** claim-to-source entailment requires an independent evaluator with source-complete, attributable evidence. Deterministic sha/JSON checks alone are insufficient.
5. **ChatGPT/native host:** only an **installed and callable** native output bridge can observe a real host delivery event and return an event receipt. Node cannot synthesize that event. Markdown or a shell file cannot install an overlay.

## Lessons from C77 → C93

- C77 builds an Actions artifact containing 34 hash-qualified files. A prior cold host connector could read GitHub metadata but not retrieve the binary artifact into Node. Manual upload succeeded once; this is not automatic transport.
- C84's `scripts/c84-build-source-package.mjs` depends on `scripts/c81-create-git-proof.mjs`, which uses git cat-file on a real local checkout. A prebuilt C77 Actions ZIP does **not** itself contain the Git proof. The source's raw commit and all reachable tree objects must be acquired and verified, not simulated.
- C90 provides C85→C81→C84→C86 causal structure, but on its original C70/C82 voice is deterministic repository fallback/guard. C91 adds model callback with ten ontology axes; C92 opens actual Responses HTTPS requests, a second reviewer, independent process checks and writes a host-owned surface; C93 removes an obsolete hardcoded source head and introduces local readback.
- None of those commits installs a ChatGPT-native ingress/delivery hook, provisions OpenAI credentials, proves a factual claim by a second model, or authenticates independent human-session outcomes.
