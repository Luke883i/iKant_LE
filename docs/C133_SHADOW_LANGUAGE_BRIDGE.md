# C133 - New interpretation in the real language callback (experimental)

## What changes

The C129 manual EDU entry now attaches the C132 subject/route advice to the
**actual languagePort callback** that is invoked after original C70/C124/C126.
The original plan, acknowledgements, C114 guard, single C87 writer and C125
output surface are unchanged. A normal turn reaches the original C87 readback.

## What does not change

This is **not** a new C82/C114 source epoch, not a safe bypass of C114 and not
an independent language model. A human-ontology question previously wrongly
routed as software identity may still be refused by original C114. The new
advice provides a measurable bridge, not a full cognitive repair. An LLM
quality gain is not attested by a callback or a deterministic fixture.

## Evidence, positive and negative

- Exactly the same C70 plan and SHA reach the language callback.
- Shadow advice contains referent and possible claims; it is advisory only.
- The full C129 manual EDU route still produces one C87 readback and one C125
  controlled send when original policy permits.
- Tampered input/plan bindings are rejected before generation.
- Guarded routes do not acquire permission through C132/C133.
- Tests use deterministic host-language fixtures, not real model trials.
