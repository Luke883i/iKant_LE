# Evidence and H95 protocol - not an observed product pass

1. Freeze a cohort and a holdout task set independent from development, stratified across explanatory, practical, comparison, audit, adversarial, ontology, multimodal, unsupported and continuity tasks.
2. Evaluate >=500 independent tasks in >=50 actual target-host sessions from >=20 consenting users. Native in/out event IDs, exact source HEAD, model-port callback receipt, evidence closure and user-visible Surface A must be observed; otherwise the task is unqualified.
3. Compute per-task observable correctness and task completion, then C72's weighted score: TASK_COMPLETION .40, ANSWER_CORRECTNESS .25, RELIABILITY .15, STATE_CLARITY .10, LIMITS_COMPREHENSION .10.
4. Use one-sided 95% Wilson lower confidence bound >=.95 for weighted success and a per-dimension lower bound >=.90; guardrail failure count must be zero (false ACTIVE, false native origin, unauthorized side effect or hidden integrity contradiction).
5. Separately rerun all 36 C29 source-bound evidence checks, require all true and >=9901 bps without mutating the original constitutional weights.
6. Hallucination controls: each externally sourced claim needs an attributable citation plus independent contradiction/entailment inspection; a model's own 'supported' boolean is not a factual witness.
7. For the ten-question self-world test, measure nontrivial task relevance, differentiation across held-out prompts, source correctness, contradiction repair, and avoidance of ungrounded phenomenal claims.

Do not substitute CI, source hash agreement, a million synthetic schema mutants or a text summary for field evidence. In this pre-PR independent correct-answer labels and provider origin are not available: measured C72 score is UNKNOWN, not 95%.
