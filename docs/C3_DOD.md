# C3.ORIENTATION_CAPSULE_UNIVERSAL_NODE_GATE — DoD

## Intent

Make local-host bootstrap fast and pre-guided without weakening admission: bounded orientation before acceptance, one human gate, real Node proof, automatic pending-intent resume, universal Node turn routing, iKant narrative Surface A and DOCX-owned technical Surface B.

## Required host assumptions

- canonical repository link is predeclared;
- `git clone` unavailable;
- `gh` unavailable;
- direct local DNS resolution of `github.com` unavailable;
- authorized GitHub connector/API is preferred; permitted raw/web access is fallback.

These are target-host operating assumptions, not universal claims about all environments.

## Global DoD

- pre-accept repository acquisition is bounded to the declared five-file capsule and one metadata projection;
- Terms presentation freezes further repository acquisition;
- exact current-session `I ACCEPT` is the sole human admission gate;
- completed forbidden pre-accept acquisition is non-retroactive and makes the chat `SESSION_NONCONFORMING`;
- a breached chat requires a fresh session for conforming iKant; later acceptance cannot clean it;
- first substantive user intent can be preserved before acceptance and resumes automatically after successful activation;
- auto-bootstrap executes a real Node.js 20+ probe with persistence/readback checks;
- false ACTIVE after probe/init failure is impossible;
- every host-permitted user input enters the Node runtime;
- every substantive ACTIVE Surface A is bound to a same-input Node dispatch receipt;
- no direct-model/simple-question fast path exists;
- every substantive ACTIVE answer requires same-turn DOCX write and exact readback before release;
- ordinary Surface A remains iKant narrative voice and excludes technical plumbing;
- Node receipt, capsule state, telemetry and DOCX have authority zero;
- host/system/safety/law constraints precede the local contract;
- single writer and hash-linked ledger remain the persistence spine;
- no database, broker, model SDK, second writer or second lifecycle state machine is added.

## Wow effects as runtime properties

1. **ONE_PASTE_BOOT** — the first substantive request is stored as pending intent; after exact acceptance, successful auto-bootstrap resumes it without repetition.
2. **SELF_DESTRUCTING_CONFORMANCE** — completed forbidden pre-accept access permanently prevents conforming activation in that chat and routes to fresh-session remediation.
3. **INVISIBLE_NODE_SHELL** — every input is locally dispatched through Node; the human sees iKant, while receipts/runtime/backlog remain outside ordinary Surface A.
4. **WARM_ZERO_CEREMONY** — a valid epoch does not repeat admission; fingerprint/capability drift still fails closed.

## Qualification gate

- deterministic unit/E2E tests: all PASS;
- contract/lifecycle check: PASS;
- runtime-semantic mutation corpus: exactly 1,000,000 cases;
- strata: exactly 500,000 ordinary, 300,000 edge, 200,000 stress/adversarial;

## Claim boundary

A PASS is engineering evidence for the declared runtime invariants over the tested corpus. It is not proof of arbitrary ChatGPT/host behavior, model quality, physical-world truth, universal prompt-injection immunity, consciousness, scientific archetype validity or formal global minimality.
