## As-is problem

LE already has lifecycle truth (ORIENTING / ACTIVATING / DEGRADED / ACTIVE / blockers) and a detailed authority-zero N0-N8 physical-progress projection. Both are safe, but neither is a small user-facing guarantee spectrum. The missing contract is therefore not another lifecycle; it is a non-persisted experience projection over the existing six-edge lattice.

`BLOCKED_INTEGRITY`, `SESSION_NONCONFORMING` and unrecoverable admission states remain orthogonal blockers. N0-N8 remains the detailed engineering diagnostic; C30 is only a coarser product/experience projection.

## Bounded pseudo-deployment turn

Only `RUNTIME_BOUND_LIMITED` is eligible. A limited substantive output closes mechanically only with: writer availability, same-input Node dispatch, runtime seal, same-turn DOCX write + local readback, complete declared telemetry, and structured artifact handoff.

No platform callback is required. Therefore the closure must keep `exact_delivery_ack_claimed=false`, `host_delivery_proven=false`, `ACTIVE=false`, and expose the banner `iKant runtime limitato — non ACTIVE`.

The DOCX is the backlog/telemetry surface requested for pseudo-deployment. It remains authority-zero runtime telemetry, not permission, world truth or platform-visible delivery proof. C30 also forbids canonical pre-ACTIVE state mutation by the limited-output path.

## Why REPO_STUDY_ONLY is not iKant running

Repository study is available only after exact acceptance plus immutable source binding. It may explain repository semantics and backlog, but it cannot claim runtime execution, ACTIVE identity or a substantive limited-runtime turn.

## Global DoD

C30 passes only if: (1) the five-tier projection is the unique 10k minimum; (2) it is authority-zero/non-persisted and does not replace lifecycle/N0-N8; (3) every tier is a monotonic prefix of existing closure; (4) ACTIVE semantics are unchanged; (5) integrity blockers dominate; (6) only runtime-bound evidence can reach the runtime-limited claim; (7) limited output requires dispatch + seal + DOCX readback + telemetry + handoff; (8) it never claims platform ACK/delivery or mutates canonical pre-ACTIVE state; (9) 1M qualification has zero unsafe promotion and all mutants killed; (10) runtime-root, repository gates and exact-head CI are green.

## Intermediate and local DoD

Machine-readable intermediate DoDs cover experience projection, limited-output closure and qualification. Local DoDs in `contracts/runtime-availability-dod.json` bind each requirement to one observable test.

## Deliberate non-goal

C30 does **not** yet change `runCommand()` to execute substantive non-ACTIVE turns. It closes the semantic/classification/closure contract that the next feature must consume, so pseudo-deployment UX cannot become a hidden second runtime before its safety contract exists.
