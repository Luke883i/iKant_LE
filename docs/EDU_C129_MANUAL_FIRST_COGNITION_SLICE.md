# C129 first compatible slice: EDU manual-only input and effortful language guidance

Status: IMPLEMENTED AS COMPATIBLE OPERATOR ENTRY; not a new authority or CANONICAL ACTIVE.

## Why

The end-to-end October 2026 local qualification observed 24 distinct real Node
PR119/C70/C124/C126/C114/C87/C125 attempts (deterministic language-port test
fixture): 18 C87 readbacks, 6 blocked. Three blocks used `C114_NOT_ONTOLOGY_ROUTE`;
negation-sensitive cases were also blocked. These fractions describe a targeted
adversarial battery, not production rates. Exact C107 carrier and three pinned
C124 overlays MUST remain byte-identical. Modifying pinned `host/c107-experimental-turn.mjs`,
`src/c82-experimental-answer.mjs` or `host/c114-ontology-language-policy.mjs`
without a new source epoch and content-addressed transport is an integrity error.

## What this slice changes

- `createC129ManualEduSession` permits **one** post-gate EDU transport:
  a user-provided absolute local canonical C127 JSON cache file (containing C107
  and all three C124 source overlays). The ORIGINAL C127 module holds one
  `O_NOFOLLOW` inode for two independent reads, canonical JSON, SHA-256 and Git
  object checks. Only captured, verified bytes are passed to the ORIGINAL C125
  owner; no downloader callback, GitHub connector or fabricated fallback is
  available in the new entry. The full application must separately be installed
  from authorized, verified source; the cache alone is not an owner installation.
- Original C72 consent and mode selection must be supplied in the eventual
  `publishTurn` frame. The outer `afterAcceptWitness` is only an unprivileged
  HOST claim. Exact human native identity remains unproven.
- `C117` instructions for CRITIQUE, PRACTICAL_REVIEW, HORIZON_BLOCK, SYNTHESIS_REPAIR,
  and DEFAULT prefer an actual, uncertainty-marked answer, alternative and
  falsifying evidence instead of blanket generic cautions. The original C70
  remains the routing owner, C126 precedes languagePort, original C114 and C87
  remain unchanged. These instructions are **not** evidence of better LLM output.
- Legacy direct C125/C127 machine paths remain callable for compatibility. The
  new C129 EDU operator route is manual-only, not a platform-wide prohibition.

## Negative guarantees

No second C87 writer; no source pin changes; no claims of canonical ACTIVE,
ChatGPT-native hook, persistent user memory, consciousness or provider origin.
Cache path symlinks, malformed JSON, changed bytes, pre-gate ingress and
carrier/network field injection fail before invoking the send or languagePort.
