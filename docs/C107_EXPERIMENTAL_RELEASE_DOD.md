# C107 — Minimal experimental cognitive prototype: physical DoD

## Promise and evidence standard

After physically installing **one source artifact** at an exact Git commit, a Node 22 host can execute `avvia iKant` locally, show original Terms, consume later exact `I ACCEPT`, later `EXPERIMENTAL`, then a distinct cohost opt-in. The following user questions traverse **original C70** cognitive computation, optional externally supplied language bound by **original C100**, and the **original C87** single-writer ledger. The host presents unchanged `voice_utf8` before diagnostics.

This is a **host-local experimental prototype**, not C59 ACTIVE, C77/C84, canonical owner, independent model provider, native ChatGPT hook, persistent cognitive state, or consciousness.

## Measured minimal *qualified candidate*

At source epoch of PR #113, `scripts/c107-pack.mjs` admits an exact finite set of 27 files: 24 reused original repository objects, 3 C107 runtime and local CLI objects. The GitHub tree reports **192,065 UTF-8/raw source bytes**. This is **73.9% less** than C104's historical 65-source / 735,336-byte source census. The one-transfer content-addressed JSON package is larger than raw sources due to base64 and envelopes; the test reports actual transfer bytes.

This is the **smallest closed candidate demonstrated by this PR**, not a global minimum proof over all possible architectures. Only code and data necessary to this *chosen experimental contract* are included. Terms/readme/admission/C70 core/functional psyche+self-world/C82/C100/C87/local shell are included. C71's 70 anchor census, C77 and C84 are excluded by design.

## Release gates (CI must execute them, not infer them)

1. **SOURCE**: exact Git HEAD/path Git-blob IDs; package SHA-256; members reopened after an isolated physical extraction.
2. **COMPUTE**: two distinct inputs, both processed by original C70; **second turn reports two in-invocation C70 episodes** (not just C87 count); two physical Node processes.
3. **VOICE**: C100 binding checks the UTF-8 voice hash; host draft remains explicitly untrusted and is never invented by the repo.
4. **CONTINUITY**: context supplied as a bounded host RAM window of maximum four previous inputs, hash-bound to C87 latest state; tampered/mismatched context rejected; C87 reopened after each process; nonce replay and ledger corruption rejected. C87 stores only hashes/telemetry.
5. **SHELL**: literal `avvia iKant` and original C72 admission followed by two ordinary turns and `GET LEDGER` in a real local Node process. No silent synthetic opt-in.
6. **FALSIFICATION**: 1,000,000 deterministic negative input/memory/voice envelope mutations in 25 families plus 10,000 positive controls. These are **not** model calls or live ChatGPT sessions.
7. **NON-CLAIMS**: native host event/delivery/source-origin attestation, cross-restart cognitive context persistence, arbitrary human-language quality and user-experience latency all remain OPEN unless separately observed.
