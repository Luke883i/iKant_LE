# C44 — Methodological bootstrap, runtime context and ASCII shell

C44 makes the local-host prompt a methodological cold-start kernel rather than a duplicated planner. Before every attempt or retry the model consults only bootstrap registries already owned by the repository; on impediment it re-enters the single entrypoint and retries only an owner-returned NEXT. No new registry or retry memory is introduced.

Declared session context references are never discovered by search. A reference may affect runtime behavior only when it is a content-addressed runtime member and survives local readback. C44 ships `stile_comunicativo.md` with effect exactly `VOICE_STYLE_ONLY`.

After Terms acceptance bootstrap output is owner-rendered in the deterministic ASCII shell. After runtime ownership only the validated runtime Session Shell is printed; the model may not reframe it.
