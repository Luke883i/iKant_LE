# C29 — Ontological Promise Closure

C29 makes the repository's overall ontological promise explicit, measurable and actionable without creating a new lifecycle, writer, planner or source of truth.

The mining pass reviewed all 20 machine contracts plus the constitutional/narrative entry points. The 20 contracts contained 1,733 normative candidate leaves before semantic deduplication. They collapse to 36 irreducible intentions across nine domains:

The canonical list, owner, observable, negative test and recovery rule live in `contracts/ikant-le.json#ontological_promise`.

## What "overall ontological promise" means

The promise is not a metaphysical claim. It is the repository-local statement that all 36 atomic intentions remain simultaneously true.

Each atom has a weight. Total = 10,000 basis points. Respect requires **>99%**, encoded as `score_bps >= 9901`.

The minimum retained atom weighs 150 bps. Therefore loss of any retained atom necessarily moves the score below 99.01%. This makes every atom causally necessary and removes the need for a second hard-gate system.

The assessment is authority-zero, non-persisted and scoped to repository-conformance evidence. It is not current-host proof, external-platform observation, phenomenology or world truth.
