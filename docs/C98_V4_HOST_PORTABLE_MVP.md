* **Host-file transport**: where the platform has mounted an approved file, C98 v4 now *actually reads* a file through a source-bound fd, rejects symlink/hardlink/path traversal, double-reopens the exact bytes, and passes them to existing C98 ZIP→C82→C84 adapters. This proves local byte transport; manual upload is last resort and **does not authenticate GitHub origin**.
* **Single C77 artifact**: use the C77 Actions artifact produced *after* the source commit and keyed to that exact HEAD/manifest; one delivery and 34 verified members. Prefer it to 34 host-to-Node callbacks. Do not commit a ZIP claiming the identity of its own Git commit; that introduces circular source identity. Package managers install software, not a native ChatGPT callback or event witness.
